# Web of Shadows Enhanced

An enhanced, fan-made launcher for **Spider-Man: Web of Shadows (PC)**.

Web of Shadows Enhanced is a free, open-source project designed to improve the experience of playing Spider-Man: Web of Shadows on PC, providing additional tools, customization options and an interactive 3D character viewer.

## Features

- **3D Character Viewer:** Preview the game's original 3D character models, animations and textures.
- **Skin Management:** Browse and manage custom skins and texture modifications.
- **Game Configuration:** Access additional game settings and configuration options.
- **Modding Support:** Integrated uMod support for real-time texture replacement.
- **Controller Support:** Additional fixes and configuration options for gamepad controls.
- **Game Fixes:** Selected fixes and improvements for the PC version.

## Requirements

- Windows 10 or Windows 11.
- Spider-Man: Web of Shadows for PC, version 1.1.1.11540.
- Microsoft Edge WebView2 Runtime, if not already installed.

Some features and fixes are specifically designed for the supported game executable version.

## Installation

Download the latest release from the [Releases](../../releases) page.

The original game is not included. You must own a copy of Spider-Man: Web of Shadows for PC.
