You don't need to touch these folders.
In the launcher, open the Suits tab and drag a .tpf file onto the window (or use the Add skin button).
The launcher works out whether the skin is for the red suit, the black suit, both (2 in 1) or another model
and keeps it here. To delete a skin, use the X on its thumbnail.

Voce nao precisa mexer nestas pastas.
No launcher, abra a aba Trajes e arraste o arquivo .tpf para a janela (ou use o botao Adicionar skin).
O launcher descobre sozinho se a skin e do traje vermelho, do preto, dos dois (2 em 1) ou de outro modelo
e guarda aqui. Para apagar uma skin, use o X no quadradinho dela.
